# SonicForge AI — Screenshot Asset Guidelines

This directory is reserved for application screenshots displayed in the repository documentation and hackathon submission.

## Recommended Screenshots to Capture

Capture the following 5 key views at standard desktop viewport (1280x800 or 1920x1080) in **Dark Mode** for best visual presentation:

| Filename | View | URL Route | Description |
|---|---|---|---|
| `dashboard.png` | Main Dashboard | `/dashboard` | Shows quick generation metrics, quick access cards, and docked audio player |
| `music-studio.png` | AI Music Studio | `/studio` | Shows prompt input, 8 production presets, duration/tempo sliders, and generated track card |
| `stem-lab.png` | Neural Analog Stem Lab | `/stems` | Shows 4-stem mixer (Vocals, Drums, Bass, Other), Solo/Mute buttons, volume faders, and download buttons |
| `practice-studio.png` | Sargam, Tanpura & Taal Studio | `/practice` | Shows vibrating Tanpura string visualizer, 8 classical taals, and Alankar custom builder |
| `sonic-assistant.png` | Sonic Voice Copilot | `/assistant` | Shows voice chat dialog, Rime Coda speaker selection, and microphone input |

## Image Specifications
- **Format:** PNG or WebP
- **Resolution:** 1280x800 minimum (16:10 or 16:9 aspect ratio)
- **File size:** Optimize images under 1 MB each using tools like TinyPNG
- **Theme:** Dark Mode recommended to showcase the signature studio styling
